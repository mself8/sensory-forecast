# 기획서

공모전 접수양식이 곧 기획서입니다. 양식 파일은 연락처와 서명이 들어가므로 레포에 올리지 않고, 내용 초안을 이 폴더에 마크다운으로 씁니다.

## 일정과 제출

- 접수 마감: 2026-11-15 23:59
- 1차 서류심사 결과: 2026-11-23
- 2차 최종 PT: 2026-12-03 ~ 12-04
- 제출: 작성하고 서명한 접수양식을 `appdevchallenge@hyundai-partners.com`으로 보냅니다.
- 메일 제목: `[차량용 앱 개발 공모전] 팀명_대표자명`
- 팀원 전원의 이메일을 참조에 넣고, 팀원 각자 동의와 서명을 합니다. 참조만으로는 동의를 대신하지 않습니다.
- 마감 전 수정은 같은 발신자 이메일로 최종본을 다시 보냅니다.
- 시연 영상, GitHub, APK는 선택이고 가산점이 있습니다. 숏폼 링크는 가산점이 없습니다.

## 양식 구성

- **01 참가신청서**: 팀명, 앱 이름, 대표자, 연락처, 참가 인원, 구성원 표
- **02 앱 프로젝트 소개**: 심사 자료입니다. 이름, 연락처, 이메일, 소속을 적지 않습니다.
- **03 개인정보 수집·이용 동의서**
- **04 대표자·팀원별 동의 확인과 서명**
