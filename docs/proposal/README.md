# 기획서

공모전 접수양식이 곧 기획서입니다. 양식 파일은 연락처와 서명이 들어가므로 레포에 올리지 않고, 내용 초안을 이 폴더에 마크다운으로 씁니다.

## 일정과 제출

공식 안내 기준입니다. 근거는 [제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission), [심사](https://appdevchallenge.auto-hmg.io/guide/judging-awards), [FAQ](https://appdevchallenge.auto-hmg.io/faq)와 공지 6·7·8입니다.

- **접수 마감**: 2026-11-15 23:59, 한국 시각
- **1차 서류심사 결과**: 2026-11-23, 합격 20팀
- **2차 최종 PT**: 2026-12-03 ~ 12-04. 그때까지 실제로 동작하는 앱을 완성해야 합니다.

**메일**

- 받는 곳: `appdevchallenge@hyundai-partners.com`
- 제목: `[차량용 앱 개발 공모전] 팀명_대표자명`
- 팀원 전원의 이메일을 참조에 넣습니다. 팀원 각자 동의와 서명을 해야 하고, 참조만으로는 동의를 대신하지 않습니다.
- 양식은 DOCX와 PDF 모두 됩니다. 전자서명과 서명 이미지 모두 인정됩니다.
- 본문에 GitHub 저장소 주소, APK 경로, **최종 커밋 해시**를 적습니다. 심사는 그 커밋으로 합니다.
- 수정할 때는 처음 보낸 주소에서 제목 앞에 `[수정제출]`을 붙여 보냅니다. 전체 자료, 서명한 동의서, 참조를 모두 다시 넣어야 최종 접수로 인정됩니다.

**가산점**

- 시연 영상과 GitHub 저장소를 내면 단계별 가산점이 있습니다. 화면 녹화도 인정됩니다.
- GitHub에는 소스와 `apk/팀명_앱이름_release.apk`를 함께 올립니다. 실행되는 release 버전이어야 합니다.
- 비공개 저장소는 **11-16까지 공개로 바꾸고 11-23까지 유지**해야 가산점이 들어갑니다. 공개가 어렵다면 소스와 APK를 묶은 압축 파일의 다운로드 주소를 마감 전에 메일로 보내도 됩니다.
- 숏폼은 가산점이 없습니다. 별도 상이 있고, 30초~1분 세로 영상에 `#HMG차량용앱개발공모전`을 답니다.

**README에 꼭 있어야 하는 것**

- 앱 이름과 한 줄 소개
- 실행 방법
- 테스트 환경과 필요한 설정
- 개발에 쓴 Pleos Connect 에뮬레이터 버전과 화면 규격
- APK 위치

**지켜야 할 것**

- 공개 문서에 있는 SDK 기능만 씁니다. 문서에 없는 기능은 기획서에 향후 계획으로 씁니다.
- 음성 인식은 SpeechToText SDK만 씁니다. 차 마이크 소리를 외부 음성 인식 서비스로 보내면 안 됩니다.
- 이미지, 음원, 글꼴, 오픈소스는 사용 권한을 지키고 출처를 밝힙니다.
- 기획서에 사실과 다른 내용을 쓰면 선정이 취소될 수 있습니다.

## 메일 본문 틀

팀명, 대표자명, 저장소 주소, 커밋 해시가 정해지면 채웁니다. 첨부는 서명까지 마친 접수양식 하나입니다.

```
제목: [차량용 앱 개발 공모전] 팀명_대표자명

안녕하세요. 차량용 앱 개발 공모전 접수양식을 보내 드립니다.

- 팀명: 팀명
- 앱 이름: 앱 이름
- 첨부: 접수양식(기획서와 팀원 전원 서명 동의서)
- GitHub 저장소: 저장소 주소
- 최종 커밋 해시: 커밋 해시 전체
- APK 경로: 저장소 apk/팀명_앱이름_release.apk
- 시연 영상: 저장소 docs/video/sensory-forecast-demo.mp4

팀원 전원을 참조에 넣었습니다. 감사합니다.
```

- 받는 곳: `appdevchallenge@hyundai-partners.com`
- 참조: 팀원 전원
- 커밋 해시는 `git rev-parse HEAD`로 확인합니다. 메일을 보낸 뒤에는 그 커밋을 바꾸지 않습니다.
